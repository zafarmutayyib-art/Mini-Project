## 📌 Project Overview

The **To-Do List Application** is a simple and user-friendly web application designed to help users manage their daily tasks efficiently. Users can add new tasks, mark tasks as completed, and delete tasks when they are no longer required.

The application is developed using **HTML, CSS, and JavaScript**, making it lightweight, easy to use, and suitable for beginners who want to understand basic web development concepts.

---

## 🎯 Objectives

* To manage daily tasks in one place.
* To make adding and completing tasks simple.
* To provide an easy-to-use task management interface.
* To demonstrate the use of HTML, CSS, and JavaScript in a web application.
* To practice basic DOM manipulation and JavaScript event handling.

---

## ✨ Features

* ➕ **Add New Tasks** – Users can add new tasks to the list.
* ✅ **Mark Tasks as Completed** – Completed tasks can be marked accordingly.
* ❌ **Delete Tasks** – Users can remove unwanted tasks.
* 📋 **View All Tasks** – All added tasks are displayed in an organized list.
* 🎨 **Simple and Clean Interface** – Easy-to-understand user interface.

## ⚙️ Installation

### 1. Clone the Repository

Open **Git Bash** or a terminal and run:

```bash
git clone https://github.com/bsreejacse2405l6/todolist.git
```

### 2. Navigate to the Project Folder

```bash
cd todolist
```

### 3. Open the Project

Open the `index.html` file in any modern web browser.

You can also open the project in **Visual Studio Code** and use the **Live Server** extension.

---

## 🚀 Usage

1. Open the To-Do List application.
2. Enter a task in the input field.
3. Click the **Add** button to add the task.
4. Click on a task to mark it as completed.
5. Click the **Delete** button to remove a task.
6. Continue adding and managing tasks as required.
